### Tecnologías utilizadas
* Spring Boot
* Java 25
* Maven

### Pasos para ejecutar el proyecto
1. Clonar el repositorio en su máquina local.
2. Abrir el proyecto en su IDE favorito (Eclipse, IntelliJ, etc.).
3. Asegurarse de tener Java 25 y Maven instalados en su sistema.
4. Ejecutar el comando `mvn clean install` para compilar el proyecto y descargar las dependencias necesarias.
5. Ejecutar el comando `mvn spring-boot:run` para ejecutar la aplicación.
